# 2025 年 10 月開放科技新聞摘要

## 2025-10-07 - React Foundation 將成立

The Linux Foundation 宣布其打算成立 React Foundation，作為 React、React Native 與相關專案的新中立組織載體，讓 React 與 React Native 在開放性、創新性、社群主導上得以維持與發展。 
- 原文：[Linux Foundation Announces Intent to Launch the React Foundation](https://www.linuxfoundation.org/press/linux-foundation-announces-intent-to-launch-the-react-foundation)

## 2025-09-18 — Access Now — *#NoExamShutdown：開學季反對考試期間封網的立場。* 
Access Now 報導與分析考期期間可能發生的網路封鎖情況，論述封網對學生與教育權利的危害，並向政策制定者與技術社群提出政策與技術上的建議。  
   原文：https://www.accessnow.org/no-exam-shutdown-new-academic-year/（Access Now）

**2025-09-26 — APC（Association for Progressive Communications）** — *9 月下旬新聞：職缺、計畫亮點與報告。* APC 在九月底發布多則新聞，包括徵才公告、針對性別包容的網路倡議回顧，以及計畫補助與合作進展摘要。  
   原文：https://www.apc.org/en/news（APC 新聞列表）

**2025-09-19 — FSFE（Free Software Foundation Europe，歐洲自由軟體基金會）** — *宣布參與與數位市場法（DMA）相關的訴訟程序。* FSFE 發布聲明表示將以第三方身分介入一起與 Apple 與歐盟執行（DMA）相關之聽證/訴訟，強調數位市場法在軟體自由與使用者權利上的影響，並說明其法律參與的立場與理由。  
   原文：https://fsfe.org/news/news.en.html（FSFE 新聞）

**2025-09-23 — Open Knowledge Foundation（開放知識基金會）** — *Field guide 推出：'The Tech We Want'。* OKFN 發布新指南《The Tech We Want | Read This Before You Build》，提供針對公共利益技術（public-interest technology）之建置前評估與實務建議，並配合線上活動介紹使用情境與案例。  
   原文：https://blog.okfn.org/2025/09/23/our-new-field-guide-the-tech-we-want-read-this-before-you-build/（Open Knowledge Foundation 部落格）

**2025-09-15 — Open Source Initiative（OSI）** — *組織內部更新：策略規劃與執行長職位搜尋（中旬）。* OSI 宣布進入新一輪策略規劃並啟動執行長搜尋流程，公開說明下一階段組織定位與優先事項，這類資訊同時出現在組織公告與第三方媒體報導。  
   原文範例（媒體報導）：https://www.epicos.com/article/972430/open-source-initiative-charts-next-phase-organization-executive-director-search

**2025-10-01 — ARTICLE 19** — *尼日利亞：言論自由即國家主權之關鍵（10/1）。* ARTICLE 19 發布短文，說明在當前政治背景下保障言論自由對社會與國家主權的重要性，呼籲保護記者與公民空間，並提出政策倡議方向。  
    原文：https://www.article19.org/resources/nigeria-free-expression-is-key-to-strengthen-sovereignty/（ARTICLE 19）
