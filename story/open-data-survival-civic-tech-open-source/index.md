# 開放資料存亡戰：公民科技與開源如何阻擋資訊消失？

![開放資料存亡戰：公民科技與開源如何阻擋資訊消失？][image1]

本文編輯：劉俊彥（Ian Liu, Yanyiyi）

你是否想過，我們日常熟悉的政府網站資訊，有可能在一夜之間遭到刪改或消失？又或者，你長期仰賴的政府開放資料或 API，可能毫無預警地被移除，影響你的研究、商業應用，甚至公民監督？

2025 年初，美國川普政府重新執政後，除了縮減國際經費補助外，更深層的資訊透明度與公民知情權危機正悄然發生。美國聯邦政府大規模移除與氣候變遷、種族平等、性別認同等議題相關的政府網站與資料，短短數週內，數千個網頁與開放資料集消失。

這不僅是內容消失，更嚴重衝擊科學研究、公共政策與民主監督。例如，環境監測資料遭刪除或修改，導致氣候政策的科學依據失準；公共健康資料被移除或遭竄改，影響疫苗研究與防疫決策；政府預算與政策評估數據消失，削弱公民監督政府的能力，使民主治理的透明度與問責機制遭受重大影響。

這場開放資料刪除風暴，也讓社會更加意識到：資料並非理所當然地存在，政府開放資料的脆弱性已成為數位社會的一大風險。然而，這場危機同時促使公民科技社群、學者與資料治理專家提出應對策略，包括：透過 FAIR 原則強化資料治理，確保資料能夠有效尋找、存取、互通與再利用；推動政府公共程式碼的開源化，讓民間能在政府刪除資料後，自行備援與復原；結合公民科技與社群監督機制，建立更具韌性的開放資料生態系。

在這篇文章中，我們將探討這起資料刪除事件的來龍去脈，並整理美國社會與公民科技社群如何迅速應對、搶救資料、監督政府，以及這場資訊保衛戰所帶來的啟示。

## 🔍 政府為什麼會（或能夠）下架開放資料？

美國政府刪除資料的原因有許多，但通常可以歸納為以下幾點：

### 1️⃣ 政治立場因素

新政府若不認同前朝政策，可能會選擇移除相關資料。例如，2017 年川普政府就曾刪除美國環境保護署（EPA）網站上與氣候變遷相關的頁面，以削弱對氣候變遷政策的支持。

### 2️⃣ 法律規範的模糊地帶

許多政府資料雖然公開，但並非所有資料都受到法律保障，要求長期保存。例如，美國《資訊自由法》（FOIA）保障公民可申請取得政府資訊，但若資料已被完全刪除，就難以適用 FOIA 來要求取得歷史版本。這使得政府能透過行政命令迅速刪除不符合其政策立場的資料，而不觸犯現行法律。

### 3️⃣ 技術與預算考量，決策者忽略資訊公開

政府有時會以「系統升級」、「節省經費」或「預算刪減」為由，移除部分公開資料。但實際上，這類刪除往往不單是技術或財務決策，而是基於政治或管理層面的考量。例如，美國某些政府機關在刪除資料時，未提供任何技術性過渡方案，也未開放歷史存取權限，使外界難以確認這些資料是否確實因技術因素而消失。

## 📌 臺灣的現況補充

在臺灣，中央政府機關的「政府資料開放平臺」（data.gov.tw）有下架機制，如須下架也須各部會的「開放資料諮詢委員會」同意，而各部會如下架已經釋出開放資料，須先於[下架資料集](https://dub.sh/tw-un-ocf)預告一定天數，接著可於[歷史資料專區](https://dub.sh/tw-his-ocf)查得曾經存在過的資料。

然而，這套機制仍有改善空間，並非所有資料都會留下完整紀錄，部分資料下架的理由也未必清楚列明，可能影響公民對政府資料存續性的信任。

## 🔎 這次事件有多嚴重？

2025 年初，川普政府透過行政命令[^1]，撤銷與多元、公平包容、人權及環境相關的聯邦政策，並同步刪除大量政府開放資料。根據多個公民科技團體的綜合統計，已有超過 8,000 個政府網頁遭到刪除或修改，影響範圍涵蓋氣候變遷、醫療與疫苗研究、LGBTQ+ 相關政策文件、環境監測報告等關鍵資訊。

不僅如此，川普政府還解任美國國家檔案館（National Archives）館長，並撤換國家文書暨檔案總署（NARA）的高層官員，進一步威脅美國歷史紀錄的完整性，可能削弱政府檔案管理機制。

目前受影響的資料與影響層面：

- 🌍 環境監測資料（來自：EPA）：影響環境科學家與地方政府監測污染、制定環保政策的能力。
- 🦠 公共衛生與醫療資料（來自：CDC、NIH）：影響疫苗研究、疾病預防與公共健康決策，使防疫準備能力下降。
- 📊 人口與就業統計（來自：BLS、Census Bureau）：削弱經濟與社會政策的資料基礎，使政府、企業與研究機構難以評估勞動市場趨勢與社會發展。

這次刪除行動不僅是政策轉向，更對資訊透明與政府問責機制造成重大衝擊。開放資料的缺失，不僅影響學術研究與政策制定，還可能削弱公民的知情權，進而削減社會監督政府的能力。

## 🛡️ 公民科技與學術界如何挺身而出？

通常在行政交接期間，政府網站的資料會被備份存檔，但這次新政府不僅主動刪除資料，甚至連備份檔案也一併移除，導致大量公共資訊無法復原。儘管部分資料因公民團體與法律訴訟的壓力而得以恢復，但許多原始資料仍已永久遺失。

由於 2017 年川普政府曾大規模刪除開放資料，這次許多公民科技團體與學術機構早有準備，在川普上任前便已建立技術監測與應對機制。他們透過「監測、備份、重建、監督」四大策略，確保政府資料有持續的可近用性與透明度。

### 1️⃣ 即時「監測」政府網站變動

美國許多政府機構使用 GitHub 來管理官網與開放資料的程式碼變更，這讓公民科技團體能夠：

- 透過 GitHub Commit History 追蹤網站變更：例如在川普上任的頭幾天，General Services Administration（GSA）轄下的數位服務團隊 18F 的 GitHub 資料庫中，出現大量的 commit（提交紀錄），清楚顯示聯邦網站內容如何被修改或刪除[^2]。（[GitHub commit 原始連結](https://dub.sh/18f-ocf-del)）
- 監測程式碼變更以揭露政策意圖：一個典型案例來自於衛生與公共服務部（HHS）旗下的「Head Start」計畫資料庫。開發人員在 GitHub 上建立了一個名為「Remove-DEI」（移除多元、公平、包容資料）的 commit，專門實作移除敏感詞彙的程式變更[^3]。（[GitHub commit 原始連結](https://dub.sh/hhs-ocf-del)）

而一些程式開發者撰寫腳本，使用自動化爬蟲技術（如 Web Archive、Common Crawl）監測政府資料是否被修改或刪除。

- 自動比較白宮和各部會網站新舊版本之間的差異，並透過社交媒體即時播報異動情況。（[原始專案頁面](https://dub.sh/whiteh-mi-ocf-del)）
- 環境資料與治理倡議（EDGI）[^4] 在 2016 年川普上台前就開始追蹤美國環境與能源類網站，監測數千頁內容的變動。今年，他們的監測系統第一時間發現 EPA 的環境正義篩選地圖（EJScreen）被撤下——當時一名教授在課堂中打開該網站，發現無法訪問，隨即在社群平台上發布截圖與警訊，迅速引發關注。（[EJScreen 備份站](https://dub.sh/ejs-ocf-del)）

在政府尚未正式對外公告相關政策變更前，民間已透過技術手段「預先察覺」，為後續的公民行動爭取了寶貴時間。

### 2️⃣ 緊急「備份」關鍵資料

川普勝選後，美國的研究圖書館與開放資料社群迅速進入「備份戰時狀態」，確保被刪除的政府資料不會徹底消失。事實上，2016 年川普首次當選後，開放資料與學術社群就已開始組織資料保護行動，2025 年再度面臨相同挑戰時，這些組織迅速啟動備援機制。

- [Data Refuge（資料避難所）](https://www.datarefuge.org/)與 [EDGI（環境資料與治理倡議）](https://envirodatagov.org/)：這兩個計畫原先在 2016 年發起，2025 年川普政府再次上台後，它們迅速升級應對。EDGI 組成[「公共環境資料夥伴網絡」（Public Environmental Data Partners）](https://envirodatagov.org/epa-removes-ejscreen-from-its-website/)，確保氣候科學與環境監測的關鍵資料集被完整保存，並建立可檢索的資料庫。
- 開放儲存與資料分流：志工與學術機構透過 [OSF（開放科學框架）](https://osf.io/)等開放儲存庫，將這些被刪除的資料重新上傳，並在 DataRescue@、[FindLostData](https://findlostdata.org/about) 等專門網站建立索引，方便研究人員與公民查找。
- 國會圖書館與網路檔案館（Internet Archive）合作，透過[「任期終端網站檔案計畫」（End of Term Web Archive）](https://dub.sh/eot-ocf)，在總統換屆前大規模爬取 *.gov 網域的網站內容，確保政府發布的資訊有完整備份。該專案提供了前後任政府網站內容對照的可能，使川普政府的刪改行為有跡可循。

這些備份不僅為研究人員繼續研究提供了資料來源，也為未來追究此類刪改行為提供了證據保全。

### 3️⃣ 以開放科技「重建」遭刪除的政府工具與資料

開源運動在這場「開放資料存亡戰」中發揮了關鍵作用。由於美國政府部分數位工具原先是以開源專案形式開發，這讓公民社群能夠在官方關閉服務後，自行鏡像備份或重新部署替代方案。而開放資料的特性，也讓這些資料的可及性得以合法延續。例如：

- 📍 🌎 氣候與經濟正義篩選工具（[CEJST 鏡像網站](https://edgi-govdata-archiving.github.io/j40-cejst-2/en/downloads#3/33.47/-97.5)）：這是一款在拜登政府期間推出的開源地圖工具，用於視覺化顯示弱勢社區的氣候風險。川普上台後不久，該工具被關閉並撤下。然而，由於它的原始碼仍存於 GitHub，環境資料社群迅速建立鏡像站，確保公眾仍能使用相同的功能。
- 📍 🏙️ 氣候變遷是真實發生的（[「Climate Change is Real」鏡像網站](https://dub.sh/real-ocf-del)）：2017 年，川普政府下架 EPA 氣候變遷網站，試圖削弱政府對氣候變遷問題的立場。芝加哥市政府決定開源 EPA 原始網站的程式碼，並將內容鏡像備份至市府網站，建立「Climate Change is Real」網站。隨後，全美十多座城市響應這項行動，紛紛在自己的政府網站上發布 EPA 氣候資訊的完整備份。
- 📍 🖥️ 氣候鏡像（[Climate Mirror 計畫網站](https://climatemirror.org/)）：這是一個專門用於備份美國政府氣候開放資料的專案，確保學術界和民間研究機構仍能存取關鍵資料與資料，即使官方網站已關閉。其技術策略利用分散式備份架構，確保資料在多個國際伺服器間同步存儲，降低單點失效的風險。

開放原始碼搭配開放資料形成自主性，即使政府刪除官網，社群仍可透過 GitHub 或其他平台重建相同工具。搭配分散式備援減少單點風險：透過鏡像備份技術，公民團體確保即使政府關閉一個網站，資料仍能存活於多個伺服器上。

### 4️⃣ 法律行動與政策「監督」倡議

除了技術備援與公民監督，法律手段也是本次反制政府刪除開放資料的重要戰場。公民團體與法律機構透過訴訟、行政監督與立法倡議，試圖阻止不當的資料刪除行為，並為未來的資訊保護建立法理依據。環境法律組織 Earthjustice 在 2025 年 3 月，代表有機農業業者等原告，對美國農業部（USDA）提起訴訟，指控該機構刪除氣候相關網頁，要求立即停止抹除行為並恢復已下架內容。

公共衛生領域的勝訴案例：針對疾病管制與預防中心（CDC）移除公共衛生資料的案件，法院裁定 CDC 必須重新上線被刪除的醫學參考資料，並強調聯邦機構未經正當程序下架攸關公共利益的資訊，可能構成「武斷濫權」，違反《資訊自由法》（FOIA）。這項判決為其他領域的資訊保護訴訟提供了重要法理支持。

- FOIA（資訊自由法）請求：強迫政府重新公開被刪除的資料。由於美國 FOIA 保障公民獲取政府資訊的權利，許多公民團體透過該法提出資訊請求，迫使政府重新釋出遭刪除的資料。「資料解放計畫」（Data Liberation Project）系統性地提交 FOIA 申請，要求聯邦機構交出已從官方網站撤下的資料集與政策報告，並將取得的資料重新上傳至公共存取平台，讓大眾自由下載使用。
- 這種「以請求逼公開」的策略，即使在政府刻意關閉主動公開管道的情況下，仍能透過法規強制釋出關鍵資料。
- 國會調查：多位議員要求國會調查 2025 年的資料刪除事件，審視這些行為是否違反《開放政府資料法》（2019 年通過，要求聯邦資料預設為開放狀態）。
- 透過立法強化：倡議者主張修訂現行法律，例如要求聯邦機構在下架資料前需公告理由與替代方案，並設有公民申訴機制；強化資料保存義務，將公共科學資訊視為國家檔案，納入 NARA 保護範圍，避免因行政更迭導致歷史資料的喪失。

### 🌍 FAIR 原則能如何幫助公民社會保存資料？

在這次美國聯邦政府大規模刪除資料的事件中，過往資料部份有依循部份 FAIR 原則（Findable、Accessible、Interoperable、Reusable，即「可尋找、可近用、可互操作、可重複使用」）的建置或管理，也成為公民社會應對開放資料危機之餘得以仰賴的。

FAIR 原則最初由學術界提出，主要用於研究資料管理，但近年來其分別的觀念也有應用於政府開放資料的治理，確保資訊即使在官方刪除後，仍能被尋找、存取與利用。在本次危機中，也有學者提出 FAIR 原則的價值，實踐於以下幾個面向中：

- 可尋找性（Findable）：讓資料不會因政府刪除而消失。FAIR 強調建立完善的中繼資料（Metadata），以及標準化的資料目錄，確保資料可被有效檢索。
- 可近用性（Accessible）：確保資料的自由流通，避免政府壟斷系統。FAIR 原則強調資料應開放存取，避免被封鎖於政府內部系統。
- 可互操作性（Interoperable）：確保資料可被不同系統重建與再利用。
- 可重複使用性（Reusable）：確保資料可長期被社會利用。

## 給臺灣公民社會的省思

美國這次的事件讓我們不得不思考：臺灣是否已準備好應對類似的資料刪除或篡改危機？在民主國家，政府更迭是常態，但當政府預算緊縮、行政政策轉向，導致無力維護網站與系統時，這些「資料」應如何長期保存？這將成為未來極為關鍵的議題。

### 法制化 vs. 行政命令：臺灣資料治理的脆弱性

OCF 曾在〈十年磨一法－－開放資料法制化卡在哪？〉一文中，探討臺灣目前的政府開放資料政策仍主要依賴行政命令與指引。雖然這在某些部會間行之有效，但其實高度仰賴行政慣例與長官意志，缺乏穩定的法制保障。一旦政府高層更迭，資料的開放與存續極可能因一紙行政命令而被改變，這正是美國本次事件給我們的重要提醒。

相比之下，美國的州政府在這次事件中發揮了分散式資料治理的優勢，透過較為開放的政策，使中央與地方能夠相互備援。這也呼應 OCF 先前提出的建議，法制規範應涵蓋各級政府機關，以確保資料不會因中央政府的政策變動而消失，這是臺灣值得深思與借鏡之處。

### 當開放資料遇見公共程式

臺灣近期在開放政府的發展上有所進展。在最新一期的開放政府國家行動方案中，數位發展部已將 [OCF 及各民間團體提出的開放資料發展建議](https://dub.sh/ogpocf2024)納入，推動[「深化跨部會資料開放及政府公共程式發展」](https://dub.sh/ocf-ogp-data-pmpc)[^5]。從美國這次的案例來看，公民社會與學術界能夠迅速應對資料刪除危機，部分正是仰賴開放資料與開放原始碼的協作模式。然而，僅靠政府的努力是不夠的，民間團體、公民科技社群、黑客松及學術機構如何進一步協作，共同強化資料治理的韌性，將是我們接下來應該關注的關鍵議題。

美國的民主體制相對穩健，仍發生了這場大規模的資料刪除事件，這對臺灣公民社會無疑是一記警鐘。我們必須未雨綢繆，確保關鍵公共資料不會因政治變遷而消失，並藉由公共程式碼的開源推動，進一步強化開放資料的法制化與協作機制，才能真正維護資訊透明與公民知情權。
